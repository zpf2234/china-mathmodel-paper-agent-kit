# 国一候选：结果精度、直观论证与流程图硬门禁

本规则适用于用户要求“国一、国奖、一等奖、优秀论文级”的 CUMCM 项目，并覆盖总控技能中把图密度与流程图仅视作软校准的旧措辞。目标是产出无明显短板的国一竞争候选稿，不承诺获奖。

## 1. A 类机理/物理/数学题：精度优先

A 类题不按题号机械选方法，但一旦核心为物理、几何、微分方程、连续优化或数值计算，结果精度是首要门禁：

1. 所有最终数值必须能从题面原始量、求解脚本和结构化结果文件复算，不得由图读数或手工改表。
2. 报告精度之前必须完成步长、网格、容差或样本量收敛；数值误差至少比最终报告的末位小一个数量级。
3. 至少使用一种不共享主要误差机制的复核：解析特例、独立几何实现、另一积分器、守恒/量纲、穷举小实例或高精度局部复算。
4. 连续全局结论必须说明搜索区间、边界、候选峰/根的发现方式和局部细化；未证明全局性时只称“当前最优/近优”。
5. 每问在 `metrics.json` 中保存报告精度、数值分辨率、独立复核误差和失效边界。任一缺失不得放行。

## 2. 严密推导必须转成直观证据

公式正确不等于评委容易理解。物理/数学论证必须同时回答：

- 对象在哪里、方向和边界是什么；
- 变量之间如何传递；
- 临界、最优或首次事件发生在哪里；
- 为什么排除看似合理的基线方案；
- 数值误差与模型误差分别多大。

因此每个复杂子问题至少具备两类正文视觉证据：

1. **解释证据**：机理、几何、变量关系或非平凡求解流程；
2. **结果证据**：过程状态、临界/最优构型、结果比较、误差、收敛、敏感性或不确定性。

表格只承担精确读数，不能替代过程、构型、趋势和诊断。

## 3. 问题分析与模型建立的流程图门禁

若一问满足以下任一条件，必须给出明确、直观、可编辑矢量流程图：

- 三个以上不可合并的计算阶段；
- 存在判断、循环、回退、早停或状态转移；
- 存在粗搜—细化、候选生成—筛选—复核；
- 多层装配、递归、再生、动态规划或多模块输入输出；
- 仅靠连续文字难以在 10 秒内重建求解链。

简单闭式代入、单一线性变换或三句内可以清楚说明的过程可不画。

流程图必须：

- 参考本地 50 篇优秀论文的人工学术风格，但不得像素复制；
- 一张图只承担一个问题或一个关键算法职责；
- 节点写真实对象、状态、公式量和动作，禁止“数据处理—建立模型—得到结论”；
- 判断菱形写实际条件，分支标“是/否”或阈值，回路返回真实更新节点；
- 主轴 5–8 个节点，必要时拆成“问题关系图 + 局部算法图”；
- 白底、黑灰细线、至多一种冷蓝强调色，无渐变、阴影、图标和彩色卡片；
- 最终插入尺寸文字不小于 8 pt，主轴、分支和回路在缩略图中仍可识别；
- 保留 `.vsdx` 或 `.tex`、PDF、SVG、PNG、结构化 JSON、连接审计和视觉复审记录。

## 4. 图密度与正文深度

开工前至少选择 3 篇同题优秀论文；同题不足时选择 5 篇同类型论文。候选稿与参考稿使用同一脚本统计参考文献前正文。

```text
figure_density_floor = max(0.50, 0.90 × 同题优秀论文图密度Q1)
required_figures = ceil(body_pages × figure_density_floor)
minimum_body_pages = ceil(0.90 × 同题优秀论文正文页数Q1)
```

低于任一硬下限直接 `REVISE_NATIONAL_FIRST_CANDIDATE`。只有具备图号、正文引入/解释、证据来源、生成源、最终尺寸可读和视觉 PASS 的图才计数。正文不得连续超过 3 页没有有效图或表。

## 4A. 特色主视觉图门禁

复杂国一/国奖候选通常规划 2--3 张特色主视觉图，至少一张同时连接模型机制与最终结论。完整读取 `../../cumcm-figures/references/signature-figure-standard.md` 与 `../../cumcm-figures/references/visual-identity-and-archetypes.md`。特色必须来自真实数据关系、临界边界、策略景观、时空演化或不确定性—决策联动，不来自渐变背景、图标堆叠、装饰性3D和信息图插画。

figure registry 使用 schema v3。特色图必须登记 `signature_figure=true`、archetype、核心命题、十秒结论、阅读顺序、数据链路、缩略图和最终页视觉复核；缺少这些字段时不得以“有特色”为由获得可视表达加分。国一模式至少一张合格特色图；若复合表达会重复或歪曲证据，可提交具名、绑定 claim/审查证据且经独立批准的豁免，不强制拼图。豁免不降低科学、provenance、图密度、MCP 图质量或可视表达门禁。其他常规图仍保持克制，避免每张图都复杂化而破坏论文节奏。

## 5. MCP 图形精度与质量

1. MATLAB/TikZ/Visio 必须记录真实调用来源，配置存在不等于调用成功。
2. 数据点、阈值、几何坐标和分支必须来自结果文件或结构化规格，禁止手工移动改变含义。
3. MATLAB 图保留 `.m/.json/.pdf/.svg`；TikZ 保留 `.tex/.json/.pdf/.svg`；Visio 保留 `.vsdx/.json/.pdf/.svg`。
4. Visio 导入 SVG 按源 `width/height` 或 `viewBox` 等比缩放；面板比例形变率不得超过 0.2%。
5. 参考图复刻必须固定画布、位置、线宽、文字和层级；原创图也要在最终论文插入尺寸审查。
6. 自动门禁不能替代人工视觉复核。每张核心图检查：字体压缩、标签碰撞、裁切、连接语义、留白、灰度辨识、数值一致性。
7. 核心图视觉审查失败时，必须修 MCP 规格或生成源并重新出图，不得只在 LaTeX 中缩放遮掩。

## 6. 放行

`PASS_NATIONAL_FIRST_CANDIDATE` 必须同时满足：结果精度门禁、逐问证据门禁、强制流程图门禁、图密度与正文深度门禁、MCP 图质量门禁、总分不低于 57/60、可视表达 5/5、P0/P1 为 0。否则仅可标记 `REVISE_NATIONAL_FIRST_CANDIDATE` 或 `BLOCKED`。
