# CUMCM 表格设计规范

本规范统一全文表格的类型选择、列结构、排序、数值格式和正文引用方式。
来源于 50 篇优秀论文分析：47/50 有表号交叉引用，结果验证段每千字
图表公式引用 4.89（全文最高），说明结果区域是表格的核心应用场景。

## 表格类型与适用场景

| 表格类型 | 适用场景 | 不适用场景 |
|---------|---------|-----------|
| 结果表 | 题目要求的最终输出 | 中间计算过程 |
| 参数表 | 模型参数及来源汇总 | 单一参数值（直接写入正文） |
| 对比表 | 候选方案/方法比较 | 只有一个方案 |
| 敏感性表 | 参数扫描或扰动结果 | 单参数单值检查 |
| 数据描述表 | 数据字段、单位和范围 | 原始数据全量展示 |
| 验证表 | 主结果与独立验证对比 | 单一验证指标（写入文字） |

## 结果表标准列

题目要求的最终输出表：

```text
| 问题/情形/编号 | 决策变量/输入 | 目标值/输出量(单位) | 约束余量 | 备注 |
```

- 按题目要求的顺序排列，不按内部计算顺序
- 必须包含单位
- 可选列：验证指标、置信区间

## 对比表标准列

候选方案或方法比较表：

```text
| 方案/方法 | 目标值(单位) | 关键约束满足 | 验证指标 | 选择/淘汰 |
```

- 按目标值从优到劣排序
- 同列同精度
- 淘汰方案标注淘汰原因

## 参数表标准列

```text
| 符号 | 物理含义 | 数值 | 单位 | 来源 |
```

- 来源列不可空：写"题面给定""文献[X]""拟合得到""优化结果"等
- 只收录影响结果的关键参数，不列所有中间量

## 敏感性表标准列

```text
| 参数 | 基准值 | 扰动范围 | 目标变化率(%) | 排名变化 | 结论 |
```

- 重点标记变化率超过阈值的行
- 排名变化列用"不变""逆转""微调"等明确表达

## 验证表标准列

```text
| 问题 | 主结果 | 验证方法 | 验证结果 | 偏差 | 判定 |
```

- 判定列给出 PASS/FAIL 或"偏差在容差内"

## 数值格式

- 同一表格同一列使用相同有效位数
- 单位统一放在列头，不在每个单元格重复
- 百分数注明基准（如"相对于问题一结果"）
- 区间用"[下界, 上界]"格式
- 缺失值用"—"而非空白

## 排序原则

1. 题目明确要求排序方式的，按题目要求
2. 比较类表格，按目标值从优到劣
3. 参数表，按首次出现顺序或物理分组
4. 时间序列，按时间顺序
5. 无特殊要求时，按问题编号

## 表格与图的分工

| 信息类型 | 优先用表 | 优先用图 |
|---------|---------|---------|
| 精确数值对比 | ✓ | |
| 趋势和演化 | | ✓ |
| 空间分布 | | ✓ |
| 参数与来源 | ✓ | |
| 残差和诊断 | | ✓ |
| 排名和分类 | ✓ | |
| 收敛过程 | | ✓ |
| 方案对比 | ✓ | |

**同一结果不得同时用完整图和完整表重复呈现**。
若需要同时用图和表，必须让两者承担不同的信息职责（如图展示趋势，表给出关键时刻的精确值）。

## 正文引用

- 表前说明表的职责："表 X 汇总了问题一在不同阻尼系数下的输出功率"
- 表后给出关键发现："由表 X 可知，当 $c$ 从 X 增至 Y 时，功率先增后减，
  最优值出现在 $c^* = Z$ 处"
- 不得只写"结果见表 X"而无任何解释
- 不得逐行念表

## 禁忌

- 无标题、无单位的表格
- 截图或手工排版的数值表（必须由结果文件生成）
- 原始数据全量展示（附件数据放附录或支撑材料）
- 与正文图完全重复的信息
- 表格内嵌长段文字（超过两行的说明改为脚注或正文）
